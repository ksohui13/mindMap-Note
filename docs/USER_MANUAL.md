# Mindmap 사용자 매뉴얼

- 대상: Mindmap 웹앱을 이용해 생각과 지식을 정리하려는 사용자
- 기준: 2026-08-29 현재 구현
- 범위: 회원가입·로그인, 마인드맵과 노드 관리, Markdown 상세 작성, 저장·복구, 내보내기

## 1. Mindmap에서 할 수 있는 일

Mindmap은 하나의 중심 주제에서 하위 개념을 가지처럼 확장하고, 각 개념에 Markdown 형식의 상세 내용을 기록하는 웹앱입니다.

주요 기능은 다음과 같습니다.

- 이메일 또는 설정된 소셜 계정으로 가입·로그인
- 여러 마인드맵 생성 및 관리
- 부모·자식 관계를 가진 노드 추가, 이름 변경, 이동, 접기·펼치기
- 노드별 Markdown 상세 작성과 미리보기
- 자동 저장 및 브라우저 로컬 초안 복구
- 전체 마인드맵, 현재 노드 또는 하위 트리를 Markdown 파일로 내보내기

> 이 문서는 이미 실행 중인 서비스의 사용 방법을 설명합니다. 설치, 데이터베이스 연결, 환경 변수 등 운영 방법은 [실행·환경 운영자 매뉴얼](OPERATOR_MANUAL.md)을 참고하세요.

## 2. 화면 구성

### 로그인 화면

- `로그인`: 기존 이메일 계정으로 접속합니다.
- `회원가입`: 새 이메일 계정을 만듭니다.
- `Google로 계속`, `카카오로 계속`: 운영 환경에 해당 로그인이 설정된 경우에만 표시됩니다.

### Dashboard

로그인 후 처음 보이는 `내 마인드맵` 화면입니다.

- `+ 새 마인드맵`: 새 마인드맵을 만듭니다.
- 마인드맵 카드: 제목, 최근 수정일, 노드 수를 표시합니다.
- 카드의 `⋯` 메뉴: 이름 변경, Markdown 내보내기, 삭제를 실행합니다.
- 오른쪽 위 계정 메뉴: 현재 계정을 확인하고 로그아웃합니다.

### 마인드맵 편집기

- 상단: Dashboard 이동, 마인드맵 제목, 저장 상태, 내보내기
- 중앙 캔버스: 연결된 노드와 조작 버튼
- 왼쪽 아래: 확대 `+`, 축소 `−`, 화면 `맞춤`
- 오른쪽 상세 패널: 선택한 노드의 Markdown 편집 및 미리보기

## 3. 빠른 시작: 첫 마인드맵 완성하기

처음 사용하는 경우 아래 순서대로 진행하면 가입부터 파일 내보내기까지 한 번에 익힐 수 있습니다.

1. 로그인 화면에서 `회원가입` 탭을 선택합니다.
2. 이메일과 8자 이상의 비밀번호를 입력하고 `계정 만들기`를 누릅니다.
3. Dashboard에서 `+ 새 마인드맵`을 누릅니다.
4. 자동으로 열린 편집기에서 `시작`이라는 루트 노드 제목을 원하는 중심 주제로 바꾸고 `Enter`를 누릅니다.
5. 루트 노드의 `+`를 눌러 하위 개념을 만들고, 제목을 입력한 뒤 `Enter`를 누릅니다.
6. 필요한 만큼 각 노드의 `+`를 눌러 개념을 확장합니다.
7. 노드의 `상세`를 누르고 Markdown 내용을 작성합니다.
8. 상단과 상세 패널의 상태가 `저장 완료` 또는 `서버와 동기화됨`인지 확인합니다.
9. 상단 `내보내기`를 누르고 범위를 선택한 뒤 `파일 생성`을 누릅니다.

## 4. 사용자 시나리오별 사용법

### 시나리오 A. 새 계정 만들기

1. 서비스 주소에 접속합니다. 로그인하지 않은 상태라면 로그인 화면으로 이동합니다.
2. `회원가입` 탭을 선택합니다.
3. 이메일을 입력합니다.
4. 비밀번호를 입력합니다.
5. `계정 만들기`를 누릅니다.
6. 가입에 성공하면 `내 마인드맵` Dashboard로 이동합니다.

입력 조건:

- 이메일은 올바른 이메일 주소 형식이어야 합니다.
- 비밀번호는 8자 이상이며 UTF-8 기준 72바이트 이하여야 합니다.
- 이미 사용 중인 이메일이면 화면의 오류 안내를 확인합니다.

운영 환경에 Google 또는 카카오 로그인이 설정되어 있다면 해당 `계속` 버튼으로 가입과 로그인을 함께 진행할 수 있습니다.

### 시나리오 B. 로그인하고 로그아웃하기

로그인:

1. `로그인` 탭을 선택합니다.
2. 가입한 이메일과 비밀번호를 입력합니다.
3. `로그인`을 누릅니다.

로그아웃:

1. Dashboard 오른쪽 위의 이메일 또는 원형 계정 아이콘을 누릅니다.
2. `로그아웃`을 누릅니다.
3. 로그인 화면으로 이동했는지 확인합니다.

### 시나리오 C. 새 마인드맵 만들기

1. Dashboard에서 `+ 새 마인드맵`을 누릅니다.
2. 새 마인드맵과 루트 노드가 생성되고 편집기로 이동합니다.
3. 선택된 `시작` 제목을 원하는 중심 주제로 바꿉니다.
4. `Enter`를 눌러 저장합니다.

새 마인드맵의 기본 이름은 `새로운 마인드맵 N` 형태입니다. Dashboard에서 별도로 이름을 변경할 수 있습니다.

### 시나리오 D. 기존 마인드맵 열기

Dashboard의 마인드맵 카드에서 미리보기 영역 또는 제목을 누릅니다. 편집기에 저장된 노드 구조와 위치, 접기 상태가 표시됩니다.

### 시나리오 E. 마인드맵 이름 변경하기

1. Dashboard에서 대상 카드의 `⋯` 메뉴를 누릅니다.
2. `이름 변경`을 누릅니다.
3. 새 이름을 입력합니다.
4. `Enter`를 누르거나 입력란 바깥을 눌러 저장합니다.

`Escape`를 누르면 변경을 취소합니다. 제목은 공백만 사용할 수 없으며 최대 200자입니다.

### 시나리오 F. 노드 추가하고 계층 만들기

1. 자식 개념을 붙일 부모 노드의 `+`를 누릅니다.
2. 생성된 노드의 제목을 입력합니다.
3. `Enter`를 눌러 저장합니다.
4. 더 깊은 계층이 필요하면 새 노드의 `+`를 다시 누릅니다.

노드 제목은 공백만 사용할 수 없으며 최대 200자입니다. 접힌 노드에는 자식을 바로 추가할 수 없으므로 먼저 `▸` 버튼으로 하위 트리를 펼칩니다.

### 시나리오 G. 노드 이름 변경하기

1. 이름을 바꿀 노드를 더블 클릭합니다.
2. 제목을 수정합니다.
3. `Enter`를 눌러 저장합니다.

`Escape`를 누르거나 저장 전에 입력란 바깥을 누르면 편집을 취소합니다. 저장에 실패하면 노드 안의 `다시 시도`를 사용할 수 있습니다.

### 시나리오 H. 캔버스 정리하고 탐색하기

- 노드 이동: 노드를 원하는 위치로 드래그합니다. 놓은 위치가 자동 저장됩니다.
- 화면 이동: 노드가 없는 캔버스를 드래그합니다.
- 확대·축소: 마우스 휠, 터치패드 핀치 또는 왼쪽 아래 `+`와 `−`를 사용합니다.
- 전체 보기: 노드가 화면 밖에 있으면 왼쪽 아래 `맞춤`을 누릅니다.
- 선택 해제: 노드가 없는 캔버스를 한 번 누릅니다.

연결선은 부모·자식 관계에 따라 자동으로 만들어집니다. 사용자가 연결선을 직접 추가하거나 삭제하지는 않습니다.

### 시나리오 I. 큰 하위 트리 접기·펼치기

자식이 있는 노드에는 `▾` 또는 `▸` 버튼이 표시됩니다.

- `▾`: 현재 표시 중인 모든 하위 개념을 접습니다.
- `▸`: 접혀 있던 하위 개념을 다시 표시합니다.

접기 상태는 저장되므로 편집기를 다시 열어도 유지됩니다.

### 시나리오 J. 노드에 Markdown 상세 작성하기

1. 내용을 기록할 노드의 `상세`를 누릅니다.
2. 오른쪽 패널의 `편집` 탭에서 내용을 작성합니다.
3. 렌더링 결과는 `미리보기` 탭에서 확인합니다.
4. 넓은 작업 공간이 필요하면 `전체화면`을 누릅니다.
5. 전체화면에서는 큰 화면의 경우 편집기와 미리보기가 나란히 표시됩니다. 작은 화면에서는 `편집`과 `미리보기` 탭을 전환합니다.
6. 작업이 끝나면 `전체화면 종료` 또는 상세 패널의 `×`를 누릅니다.

상세 내용은 UTF-8 기준 최대 256KiB입니다. 일반적인 Markdown 제목, 목록, 인용, 코드 등의 문법을 사용할 수 있습니다.

### 시나리오 K. 자동 저장 상태 확인하기

Markdown 상세는 마지막 입력 후 약 2초 뒤 자동 저장됩니다. 노드 제목, 위치, 접기 상태도 변경 시 저장됩니다.

화면에 표시되는 상태의 의미:

| 상태 | 의미 | 사용자가 할 일 |
|---|---|---|
| `서버와 동기화됨` | 로컬 변경과 서버 내용이 같습니다. | 없음 |
| `저장 대기 중` | 변경을 감지했고 곧 저장할 예정입니다. | 잠시 기다립니다. |
| `저장 중…` | 서버로 저장하고 있습니다. | 페이지를 닫지 않고 기다리는 것이 안전합니다. |
| `저장 완료` | 최근 변경이 저장되었습니다. | 없음 |
| `저장 실패` | 서버 저장에 실패했습니다. | 원인을 확인한 뒤 `다시 시도`를 누릅니다. |

Dashboard로 돌아갈 때는 저장 중인 상세 내용을 한 번 더 전송하지만, 네트워크가 불안정한 상태에서 브라우저를 즉시 종료하면 서버 저장을 보장할 수 없습니다. 중요한 작업 뒤에는 `저장 완료`를 확인하세요.

### 시나리오 L. 저장되지 않은 로컬 초안 복구하기

서버 저장 전에 브라우저가 닫혔거나 네트워크 오류가 발생하면 같은 브라우저에 로컬 초안이 남을 수 있습니다.

1. 해당 마인드맵에서 대상 노드의 `상세`를 엽니다.
2. `저장되지 않은 로컬 초안이 있습니다` 안내를 확인합니다.
3. 아래 중 하나를 선택합니다.

   - `초안 적용`: 로컬 초안을 편집 내용으로 불러오고 자동 저장합니다.
   - `서버본 사용`: 로컬 초안을 버리고 마지막 서버 저장본을 사용합니다.

브라우저 저장소를 삭제하거나 다른 브라우저·기기를 사용하면 로컬 초안을 복구할 수 없습니다.

### 시나리오 M. Markdown 파일로 내보내기

편집기에서 내보내기:

1. 상단 `내보내기`를 누릅니다.
2. 아래 범위 중 하나를 선택합니다.

   - `전체 마인드맵`: 모든 노드를 포함합니다.
   - `현재 노드만`: 현재 선택한 노드 하나만 포함합니다.
   - `현재 노드 + 모든 하위 개념`: 현재 선택한 노드에서 시작하는 하위 트리를 포함합니다.

3. `파일 생성`을 누릅니다.
4. 브라우저 다운로드가 완료되었는지 확인합니다.

특정 노드에서 바로 시작하려면 노드의 `⋯` 메뉴에서 `이 노드부터 내보내기`를 누릅니다. Dashboard 카드의 `Markdown 내보내기`에서는 노드가 선택되지 않으므로 `전체 마인드맵`만 사용할 수 있습니다.

내보낸 UTF-8 `.md` 파일에는 마인드맵 제목, 내보내기 범위, 개념 트리, 각 노드 경로와 상세 Markdown이 포함됩니다. 파일명은 대체로 `<마인드맵 이름>-all.md`, `-node.md`, `-subtree.md` 형태입니다.

내보내기 전에 대상 내용의 저장 여부를 확인합니다. 저장 실패 또는 처리하지 않은 로컬 초안이 있으면 파일 생성을 중단하고 먼저 해당 노드에서 저장이나 복구를 완료하도록 안내합니다.

### 시나리오 N. 노드 삭제하기

1. 삭제할 일반 노드의 `⋯` 메뉴를 누릅니다.
2. `삭제`를 누릅니다.
3. 함께 삭제될 하위 개념 수를 확인합니다.
4. 삭제가 맞으면 확인 창의 `삭제`를 누릅니다.

삭제한 노드의 모든 하위 노드와 상세 내용도 함께 삭제됩니다. 루트 노드는 개별 삭제할 수 없습니다. 삭제를 취소하려면 확인 창에서 `취소`를 누릅니다.

### 시나리오 O. 마인드맵 전체 삭제하기

1. Dashboard에서 대상 카드의 `⋯` 메뉴를 누릅니다.
2. `삭제`를 누릅니다.
3. 확인 창에 표시된 포함 노드 수를 확인합니다.
4. 삭제가 맞으면 `삭제`를 누릅니다.

마인드맵과 포함된 모든 노드 및 상세 내용이 함께 삭제되며, 앱 안에서 되돌릴 수 없습니다.

## 5. 오류가 발생했을 때

### 서버에 연결할 수 없다는 메시지가 표시됨

- 인터넷 또는 사내 네트워크 연결을 확인합니다.
- 잠시 후 다시 시도합니다.
- 계속 실패하면 서비스 운영자에게 문의합니다.

### 마인드맵 또는 상세 내용을 불러오지 못함

- 화면의 `다시 시도`를 누릅니다.
- 문제가 계속되면 Dashboard로 돌아간 뒤 다시 엽니다.

### 제목, 위치 또는 접기 상태 저장 실패

- 노드에 표시된 `다시 시도`를 누릅니다.
- 현재 서버 내용을 유지하려면 `서버 상태로 되돌리기`를 선택합니다.

### Markdown 저장 실패

- 상단 또는 상세 패널의 `저장 실패` 옆 `다시 시도`를 누릅니다.
- 실패가 지속되면 페이지를 닫기 전에 작성 내용을 별도 파일에 복사해 두는 것이 안전합니다.

### 내보내기가 시작되지 않음

- 대상 노드의 저장 상태가 `저장 완료`인지 확인합니다.
- 로컬 초안 복구 안내가 있는 노드를 열어 `초안 적용` 또는 `서버본 사용`을 선택합니다.
- 브라우저가 파일 다운로드를 차단했는지 확인합니다.

## 6. 안전하게 사용하는 방법

- 중요한 편집 뒤에는 `저장 완료` 또는 `서버와 동기화됨`을 확인합니다.
- 삭제 확인 창에서 삭제되는 노드 수를 확인합니다.
- 큰 구조 변경 전에는 전체 마인드맵을 Markdown으로 내보내 보관할 수 있습니다.
- 공용 컴퓨터에서는 사용 후 반드시 로그아웃합니다.
- 계정 비밀번호와 내려받은 Markdown 파일은 사용자 본인이 안전하게 관리합니다.

## 7. 현재 지원 범위와 제한

- 지원: 웹 브라우저 기반 마인드맵 작성, 노드별 Markdown, Markdown 내보내기
- 미지원: ZIP, PDF, PNG 내보내기, 파일 가져오기, 공유, 공동 편집
- 모바일 전용 편집 화면은 제공하지 않습니다. 작은 화면에서는 상세 전체화면의 탭 전환을 사용할 수 있지만, 전체 마인드맵 편집은 데스크톱 또는 충분히 넓은 화면을 권장합니다.
- 로컬 초안은 작성한 브라우저의 저장소에만 남으며 다른 기기와 동기화되지 않습니다.

## 8. 자주 묻는 질문

### 마인드맵 제목과 루트 노드 제목은 같은가요?

아닙니다. 마인드맵 제목은 Dashboard 카드와 편집기 상단에 표시되는 문서 이름이고, 루트 노드 제목은 캔버스의 중심 개념입니다. 각각 따로 변경합니다.

### 노드를 다른 부모 아래로 옮길 수 있나요?

현재 드래그는 화면상의 위치만 바꿉니다. 부모·자식 관계 자체를 다른 노드로 변경하는 기능은 지원하지 않습니다.

### 접은 하위 노드가 삭제된 것인가요?

아닙니다. 화면에서만 숨긴 상태입니다. `▸`를 눌러 다시 펼칠 수 있습니다.

### 상세 패널을 닫으면 작성 내용이 사라지나요?

내용은 자동 저장됩니다. 다만 네트워크 오류가 있을 수 있으므로 패널을 닫거나 페이지를 이동하기 전에 저장 상태를 확인하는 것이 가장 안전합니다.

### 내보낸 Markdown에 상세가 없는 노드도 포함되나요?

포함됩니다. 상세가 없는 노드는 파일에 `_(상세 Markdown 없음)_`으로 표시됩니다.
